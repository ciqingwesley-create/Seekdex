# Screenshot provenance

The current two PNG screenshots are generated by `scripts/generate_public_screenshots.py` using Seekdex's actual Qt widgets, Pillow-generated colored geometric shapes and fictional `D:/Photos` paths. No personal photos, external photographs, model outputs or private identifiers are included. The script does not install models or scan a photo directory.

These rendered screenshots and their synthetic input are project-created assets distributed under the project's MIT license. The program icon is the project's existing vector asset; regenerated PNG / ICO variants retain that provenance.

Older screenshots with machine paths remain only in the separately retained private repository and its private backup. This standalone public candidate starts from the cleaned snapshot and does not include those commits or images. See the pre-publication audit before publishing.
